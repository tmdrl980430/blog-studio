## 글 서식

| 요소 | 규칙 | 값 |
|---|---|---|
| 큰 소제목 `##` | 한 글에 4~7개, 내용을 말하는 제목 | 22px 굵게, 아래 2px #222 선 |
| 작은 소제목 `###` | 큰 소제목 안에서만 | 18px 굵게 |
| 본문 | 문단 3~4줄, 한 문단 한 얘기 | 16px, 줄간격 1.8 |
| 인라인 코드 | 함수·변수·명령어 이름에만 | 배경 #f1f1f1, 글자 #c7254e |
| 코드 블록 | 언어 표시, 30줄 이하 | 배경 #f8f8f8, 테두리 #e5e5e5, Consolas·D2Coding 14px |
| 표 | 비교는 문장 대신 표 | 1px #ccc 테두리, 머리글 #f5f5f5 |
| 인용 | 핵심 요약·주의 한 줄 | 왼쪽 4px #3b82f6 선, 배경 #f3f7ff |
| 이미지 | 본문 폭, 설명 한 줄, 파일명·alt에 키워드 | 가로 전체 |

## 썸네일 (타이포 카드)

- 크기 1200×630, 핵심 글자는 가운데 630×630 안 (목록에서 정사각형으로 잘려도 보이게)
- 배경: 테마·트랙 색 하나 (`theme.yaml`의 `design.track_colors`)
- 위: 트랙 라벨 + 회차 (예: "알고리즘 · 12") — 26px
- 가운데: 제목 2줄, 줄당 10자 안팎 — 60px 굵게, 흰색
- 아래: 블로그 이름 — 24px
- 예시 템플릿: 블로그 스튜디오 예상 화면 캔버스의 "썸네일 템플릿"
