## 1. 블로그 정보 정리

네이버 블로그는 네이버 아이디마다 이미 있어서, 만들기보다 정리하기에 가깝습니다. 메뉴 이름은 개편에 따라 조금 다를 수 있습니다.

1. 네이버 로그인 → blog.naver.com → 내 블로그. 주소 `blog.naver.com/아이디`의 아이디를 블로그 스튜디오 설정에 넣습니다.
2. 관리 → 기본 설정 → 블로그 정보: 블로그명, 별명, 소개글, 블로그 주제, 프로필 이미지.
3. 관리 → 메뉴·글·동영상 관리 → 카테고리 관리: {theme.categories}

## 2. 꾸미기

| 단계 | 위치 | 추천 |
|---|---|---|
| 스킨 | 꾸미기 설정 → 스킨 선택 | 흰 배경의 단순한 스킨 (스킨에 따라 글꼴·색도 바뀜) |
| 레이아웃 | 꾸미기 설정 → 레이아웃·위젯 설정 | {theme.layout} |
| 세부 디자인 | 꾸미기 설정 → 세부 디자인 설정(리모콘) | 배경 흰색, 포인트 색 {theme.accent} 하나 |
| 타이틀 | 꾸미기 설정 → 타이틀 꾸미기 | 글자형 타이틀. 이미지는 가로 966px, 세로 50~300px 기준 |
| 위젯 | 레이아웃·위젯 설정 | 프로필·카테고리·검색·최근 글. 리모콘에서 꾸며도 여기서 켜야 보임 |

꾸민 뒤 휴대폰 앱에서도 한 번 확인합니다.

## 3. 글 올리기

- **자동 채우기 (추천)**: "네이버 자동 채우기" → 앱 안 창에서 처음 한 번 네이버 로그인 → "모두 채우기". 제목·본문·이미지가 들어가고, 태그는 발행 창에서 Ctrl+V (자동으로 복사돼 있음). **발행은 직접** 누릅니다. 하루에 여러 글을 한꺼번에 올리지 마세요.

- 블로그 스튜디오의 "본문 복사 + 네이버" → 본문에 Ctrl+V.
- 코드 블록의 줄바꿈·배경이 깨지면 그 부분만 에디터의 소스코드 기능으로 다시 넣습니다.
- 같은 글을 티스토리에도 올린다면 네이버에는 도입부·정리를 다르게 쓰거나 요약본 + 원문 링크로 올립니다 (유사 문서 판정 방지).
- 이미지: 본문에 "[이미지 N: …] — 이 자리에 앱의 이미지 N을 붙여넣으세요" 줄이 있으면 그 줄을 지우고, 앱 왼쪽 "이미지" 목록에서 N번 "복사" → Ctrl+V.
- 대표 이미지: 이미지 1(썸네일, 1200×630)을 대표로 지정.


## 4. 검색 노출

네이버 블로그는 네이버 검색에 별도 등록 없이 노출됩니다.
